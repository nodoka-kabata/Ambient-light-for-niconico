# ニコニコ アンビエントライト

ニコニコ動画の視聴ページで、再生映像のアンビエント光または画面全体のぼかし背景を表示する Chrome 拡張です。

## Chrome への読み込み

1. `chrome://extensions` を開く
2. 「デベロッパー モード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダーを選ぶ
4. `https://www.nicovideo.jp/watch/*` を開いてツールバーの拡張アイコンから設定する

ソースを変更した後は、`chrome://extensions` でこの拡張の再読み込みボタンを押し、視聴ページも再読み込みしてください。

## 現在の機能

- 3層の投影を外側ほど薄く重ねるアンビエント光のオン/オフ
- 「プレイヤー周囲」と「画面全体をぼかす」の表示切り替え
- ぼかし量、広がり、フェード時間
- 描画解像度と FPS 上限による画質・負荷調整
- 前フレームを残して光の動きを滑らかにするフレームブレンディング
- WebGL レンダラー（利用できない環境では Canvas 2D に自動フォールバック）
- 上下左右の黒帯を検出して映像部分だけを投影
- 上・右・下・左の発光方向を個別に切り替え
- 画面全体モードの背景明るさ
- 画面全体モードの背景の強さ
- 画面全体モードで、カード背景を半透明化して読みやすさを維持
- 明るさ、コントラスト、彩度
- Chrome の同期ストレージへの設定保存
- 再生停止時はフレーム更新を止める
- ニコニコの視聴ページ以外では動作しない

最初の版です。ニコニコ側のプレイヤーDOM変更には追従が必要になる場合があります。画面全体モードでは動画の縦横比を保って画面全体を覆います。ぼかしを弱めに設定し、背景の明るさと強さを個別に調整できます。
