# ニコニコ アンビエントライト

ニコニコ動画の視聴ページで、再生映像をぼかした光としてプレイヤーの周囲に表示する Chrome 拡張です。

## Chrome への読み込み

1. `chrome://extensions` を開く
2. 「デベロッパー モード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダーを選ぶ
4. `https://www.nicovideo.jp/watch/*` を開いてツールバーの拡張アイコンから設定する

## 現在の機能

- アンビエント光のオン/オフ
- 「プレイヤー周囲」と「画面全体をぼかす」の表示切り替え
- ぼかし量、広がり、フェード時間
- 明るさ、コントラスト、彩度
- Chrome の同期ストレージへの設定保存
- 再生停止時はフレーム更新を止める
- ニコニコの視聴ページ以外では動作しない

最初の版です。ニコニコ側のプレイヤーDOM変更には追従が必要になる場合があります。実ページでの表示確認はまだ行っていません。
